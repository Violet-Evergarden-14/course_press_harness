# 实测记录

> 设计文档写得再好，也只有真实素材能证明它站得住。本文件记录**验证过什么行为**与由此发现的问题，不记录具体课程、文件路径或个人素材。

---

## 1. 单讲课件

**验证内容**：一份一百余页的演示文稿，含组合形状、公式对象、图片与备注页，能完整走通摄取 → 切分 → 编排 → 渲染。

**结果**：结构与课件自带的编号层级一致，没有出现「整份课件只析出一个知识点」的退化。

**由此修正**：

1. 分节最初按「知识点数的平方根」猜节数 → 改为读课件自带编号层级（[outline-generation.md](outline-generation.md) §3.0）
2. 单级编号（`2. 链式存储结构`）被当成结构 → 只认含小数点的编号
3. 示意图的节点标签（`A`、`B`、`T1`）混进正文 → 增加标签识别（[ingest.md](ingest.md) §4.1.1）

## 2. 结构信号缺失的课件

**验证内容**：一批把标题写成普通文本框、页面还带页眉的演示文稿。

**结果**：第一版**整份课件只析出一个知识点**——标题既不是占位符、也不是编号小标题，页眉还与标题同字号。

**由此补上**（[ingest.md](ingest.md) §4.1.0）：

- 按字号推断标题（≥24pt），中文优先，排除代码标识符、列表项与纯符号
- 页眉判据：同一文本出现在 **≥50% 且 ≥3 张**幻灯片上——小节标题的重复是正常的，页眉的重复是压倒性的
- 无编号时按标题连续段聚类（[outline-generation.md](outline-generation.md) §3.0.1）

修正后同一批素材从 1 个知识点变成十余个，章节结构与课件一致。

## 3. 追加讲次

**验证内容**：在已成书的三讲之后追加第四讲，重新构建。

**关键断言**：前 3 讲正文逐字节一致（diff 为空），新讲次追加在末尾。这是设计里最核心的一条承诺：新增讲次不重写既有内容。

## 4. 大纲手工修改

**验证内容**：手工把某一节的知识点移到另一节，重新构建。结果：位置保持，未被自动结果覆盖。

## 5. 文本型 PDF

**验证内容**：一份四十余页、双栏排版的讲义 PDF。

**由此修正**：双栏串行、页眉页脚混入正文、目录页被当成一节、每行独立成块导致段落破碎（[ingest.md](ingest.md) §5）。此外 `path_leak` 曾把正文里的 URL 误判为本地路径。

## 6. 排版后端

**验证内容**：同一份内容分别用 LaTeX 与 HTML/CSS 打印，测量行距与段间距。

**结论**：LaTeX 的垂直间距由 `parskip`、`baselineskip` 与各宏包胶水叠加决定，且 ctex 会在 `egin{document}` 重置其中一部分——同一文档里出现 27–35pt 的段间距，而目标值是 21pt。CSS 的 `line-height` 与 `margin` 是精确值，因此 PDF 默认改走 HTML + 无头浏览器（[rendering.md](rendering.md) §10.1.1）。
