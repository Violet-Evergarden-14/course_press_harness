# 音频对齐

> 状态：设计稿 v0.1
> 依赖：[architecture.md](architecture.md) §9
> 本文件定义对齐档位的判定、A/B 档算法、置信度模型与人工确认流程。

---

## 1. 目标

把课堂录音的转写片段映射到幻灯片，使「老师当时在讲哪一页」成为机器可用的数据。对齐结果服务于三件事：

1. 知识化时把口述内容并入对应知识点
2. 发现口述与文稿不一致（`correction` 候选）
3. 找到文稿未覆盖但口头强调的内容（`emphasis` 候选）

**对齐是可选的。** C 档（无录音）必须能跑完整流程，下游不得假设对齐结果存在。

---

## 2. 输出格式

`.study/aligned/s06.align.json`：

```json
{
  "schema_version": 1,
  "lecture": 6,
  "tier": "B",
  "confidence": 0.71,
  "segments": [
    {
      "block": "rec06-0088",
      "t": [812.5, 845.2],
      "slides": [12],
      "confidence": 0.88,
      "method": "lexical_dp"
    }
  ],
  "slide_to_segments": {"12": ["rec06-0088", "rec06-0089"]},
  "unassigned": ["rec06-0001"],
  "notes": ["第 34 页无对应录音片段"]
}
```

| 字段 | 说明 |
|---|---|
| `tier` | `A` / `B` / `C` |
| `confidence` | 本讲整体对齐质量，取各段置信度的加权中位数 |
| `segments[].method` | `anchor` / `lexical_dp` / `manual` |
| `unassigned` | 未能归属的转写片段（开场白、离题、设备噪音） |
| `notes` | 供审查阅读的问题，例如某页完全没有讲解 |

## 3. 档位判定

由 `probe.json` 与配置决定，判定过程不调用模型：

```
录音存在？
├─ 否 → C 档
└─ 是
   ├─ 锚点数 ≥ 3（且覆盖跨度 ≥ 全片 50%）→ A 档
   ├─ 锚点数 1~2 → A 档（区间外降级为 B 档方法，按段标记 method）
   └─ 锚点数 0
      └─ 转写可用？
         ├─ 是 → B 档
         └─ 否 → C 档
```

### 3.1 锚点来源

| 来源 | 识别方式 | 可信度 |
|---|---|---|
| 学生手记 | `note` 块同时含 `at.slide` 与 `at.t` | 高 |
| 备注页时间码 | 备注文本中的 `00:13:40` 形式 | 高 |
| 用户显式提供 | `study align --anchor 12:13:40` | 高 |
| 翻页提示音 | 音频事件检测 | 中（v1 不实现，保留接口） |

锚点须满足 `slide` 与 `t` 均有效。冲突检测：若锚点顺序与幻灯片序号单调性矛盾，该锚点降级为「疑似」并进入人工确认队列。

### 3.2 probe 输出

```json
{
  "audio":  {"present": true, "duration": 5412, "has_word_ts": true},
  "slides": {"count": 48, "speaker_notes": 31, "notes_with_timecodes": 2},
  "anchors":{"user_provided": 2, "detected_page_turns": 0},
  "tier_hint": "A"
}
```

`tier_hint` 仅供参考。最终档位由代理结合用户确认写入 `study.config.yaml#alignment.tier`，保证同一工作区重复运行结果一致。

## 4. A 档：锚点插值

### 4.1 算法

设锚点为按时间排序的 `(t_k, slide_k)`，且 `slide_k` 非递减。

1. 对相邻锚点之间的转写片段，归入该区间
2. 区间内按时间比例分配：

```
待分配片段 t 落在 (t_k, t_{k+1}) 内
slide(t) = slide_k + floor((slide_{k+1} - slide_k) * (t - t_k) / (t_{k+1} - t_k))
```

3. 首锚点之前、末锚点之后的片段，按最近锚点归属，并标记 `method: anchor, edge: true`

### 4.2 边界处理

| 情况 | 处理 |
|---|---|
| 相邻锚点指向同一页 | 区间内全部归该页 |
| 锚点隐含跳页（slide 差 > 5） | 保留跳页，不插值；跳过的页记入 `notes` |
| 锚点倒退 | 视为错误锚点，降级为疑似并进入确认队列 |
| 锚点时间为负或超出总时长 | 丢弃并报 `warning` |

### 4.3 为何不按字符数等分

按时间比例分配的前提是讲解语速近似均匀。若某页被反复讲解（重点页），比例分配会低估。因此当区间长度超过 3 分钟且区间内包含多页时，改用 B 档的词面相似度在区间内细分，标记 `method: anchor+lexical`。

## 5. B 档：词面动态规划

### 5.1 特征

| 侧 | 特征 |
|---|---|
| 幻灯片 | 全部文本块（标题权重 ×2）的字符 n-gram 集合，n ∈ {2,3}；剔除停用词与纯标点 |
| 转写片段 | 同上，另加拼音序近似匹配（用于识别识别错误导致的同音字，权重 0.5） |

中文不使用分词器：分词结果对跨领域术语不稳定，字符 n-gram 在小规模文本上表现更稳。

### 5.2 相似度

```
sim(seg, slide) = |A ∩ B| / sqrt(|A| · |B|)     # 余弦形式，A、B 为 n-gram 多重集
```

同时计算：

- 标题命中加成：幻灯片标题的 3-gram 出现在片段中时，`sim × 1.5`
- 数字加成：片段与幻灯片中出现相同的数字（如「第 12 页」「2 的 i 减 1 次方」）时，`+0.1`

### 5.3 动态规划

设片段序列 `S[1..N]`，幻灯片序列 `P[1..M]`。对每个片段指定一个幻灯片序号（或「不归属」），约束幻灯片序号非递减：

```
score[i][j] = max(
    score[i-1][j]   + skip_penalty,          # 片段 i 归属幻灯片 j（j 与前一相同）
    score[i-1][j-1] + sim(S[i], P[j]),       # 前进一步
    score[i-1][k]   + sim(S[i], P[j]) - gap_penalty * (j - k)   # 跳过若干页
)
score[i][0] = score[i-1][0] + unassigned_penalty              # 不归属
```

参数默认值：

| 参数 | 默认 | 含义 |
|---|---|---|
| `skip_penalty` | 0.02 | 连续多段归属同一页的代价（防止全部堆在一页） |
| `gap_penalty` | 0.03 | 每跳过一页的代价（防止无约束跳跃） |
| `unassigned_penalty` | 0.15 | 不归属的代价（开场白、离题内容应低分） |

复杂度 `O(N·M²)`；`N ≈ 200`、`M ≈ 50` 时约 50 万次计算，毫秒级。若 `M` 超过 200 页，改用 `O(N·M)` 的前缀最大优化。

### 5.4 回溯与置信度

回溯得到最优路径后，对每个片段计算：

```
margin(i) = best_score(i) - second_best_score(i)     # 与次优页面的差距
confidence(i) = sigmoid(a · sim + b · margin)        # a、b 由评测集标定
```

同时做一致性检查：若相邻片段归属的页跨度超过 8 页后又立即回退，标记 `inconsistent` 并降低置信度。

## 6. 人工确认

低置信度片段（`confidence < 0.6`）或 `inconsistent` 的片段进入确认队列，每讲通常 3~8 条。

```yaml
# .study/aligned/s06.confirm.yaml
- block: rec06-0091
  t: [1320.0, 1358.4]
  text: 这个和刚才那个性质正好反过来
  candidates: [14, 15, 16]
  auto: 15
  confidence: 0.42
  answer:            # 留空表示未确认
```

处理方式：

1. 代理逐条询问用户，或将候选写入文件交由用户编辑
2. 用户回答写入 `answer`，可为页码或 `skip`
3. 确认项标记 `method: manual`，置信度置 1.0
4. 未确认项在最终结果中保留自动值，但标记 `unconfirmed: true`

`unconfirmed` 比例记入 `review/findings.md`，超过 20% 时报告 `major`。

## 7. C 档：不对齐

- `align.json` 不生成，或生成 `{"tier": "C"}` 的空结构
- 下游（知识化）不得读取对齐结果；实现上以「对齐文件不存在」为唯一判据，禁止用空数组代替
- 覆盖率门禁在 C 档下不检查幻灯片是否被讲解覆盖

## 8. 对齐结果的使用

### 8.1 知识化时的合并

- 片段归属幻灯片 `p` → 其内容作为该页派生知识点的 `evidence` 追加
- 片段归属多页 → 复制至多页，但 `evidence` 中只保留一份，标记主归属
- 片段内容与幻灯片文本矛盾 → 产出 `correction` 候选 finding，不自动覆盖

### 8.2 口头强调的识别

满足以下任一条件的片段标记为 `emphasis` 候选，供人工确认后写入知识点 `emphasis`：

- 出现「记住」「一定」「必考」「重点」「考试」「容易错」等标记词
- 同一页相关内容被讲解超过该讲平均时长的 2 倍
- 对同一结论重复表述 2 次以上

`emphasis` 不自动写入知识点。标记词识别会产生大量误报，必须人工确认。

## 9. 质量评测

以带真值标注的 fixture（20~30 个片段的页码标注）评测：

| 指标 | 定义 | v0.1 目标 |
|---|---|---|
| 页面级准确率 | 片段归属页面与真值一致的比例 | A 档 ≥ 95%，B 档 ≥ 75% |
| 相邻页容忍准确率 | 误差 ≤ 1 页的比例 | A 档 ≥ 99%，B 档 ≥ 90% |
| 未归属率 | 被标记 `unassigned` 的真值片段比例 | ≤ 10% |
| 单调性违反 | 路径中页码倒退次数 | 0 |

B 档目标偏低是刻意的：无锚点时的词面匹配在口语化讲解与术语稀疏的幻灯片上必然失效，虚构更高的指标没有意义。

## 10. 失败模式

| 现象 | 原因 | 缓解 |
|---|---|---|
| 全部片段归属同一页 | 某页幻灯片的文本显著长于其他页 | 提高 `skip_penalty`；对超长页做长度归一化 |
| 页码整体偏移 | 录音开头有长时间无关内容 | 允许 `--offset` 指定录音起点对应的页 |
| 后半段对齐崩溃 | 中途换了录音设备或休息中断 | 支持分段对齐：`--split 00:45:00` 后分别对齐 |
| 术语密集页匹配失败 | 幻灯片文本以符号为主 | 引入公式符号的 unicode 近似匹配；失败时进确认队列而非强行对齐 |
| 中英混排 | 英文术语被识别为中文同音字 | 拼音近似匹配（§5.1），并降低该段权重 |

## 11. 实现映射（v0.1）

| 文档概念 | 命令 / 模块 |
|---|---|
| 转写 | `ingest/media_adapter.py`：优先同名 `.srt`/`.vtt`，其次本地 `faster-whisper`，都没有则写 `transcript` 缺口 |
| 档位判定 | 由音频是否存在与锚点数决定（`align.decide_tier`），不使用模型 |
| A 档 | `align.align_by_anchors`：锚点间按时间比例插值 |
| B 档 | `align.align_by_dp`：字符 n-gram 相似度 + 单调动态规划 |
| 结果 | `.study/aligned/sNN.align.json`；低置信项另存 `sNN.confirm.yaml` |
| 下游 | `apply_to_blocks` 把 `slide` 写进语音块，知识化时并入该页知识点，渲染为「讲解」小节 |

三条实现约束：

1. **C 档不产文件**。没有音频时 `.study/aligned/` 为空，下游以文件是否存在判断，禁止用空数组代替。
2. **语音转写是可替换的**。SRT 路径完全确定性，可在无模型、无音频真值的情况下测试全链路；whisper 只是可选后端，`pyproject.toml` 的 `[audio]` extra。
3. **跨源归组**。语音与幻灯片来自不同源，必须在分组前按位置合并，否则每段转写会变成独立知识点并被当作空单元丢弃。

## 12. 禁止事项

| 禁止 | 理由 |
|---|---|
| 用模型直接判断「这段讲的是哪一页」 | 不可复现、不可评测、成本高；词面方法在 B 档已足够 |
| 对齐失败时静默退化为均匀分配 | 会产生看似合理但完全错误的映射，比没有更糟 |
| 把对齐结果渲染为「录音第 X 分钟」 | 属于来源指称，见 architecture.md §6.3 |
| 在 C 档用空文件代替缺失 | 下游无法区分「无录音」与「对齐失败」 |
